# SM-S721B Evidence

This directory contains sanitized metadata derived from the supplied device logs and probe output. It intentionally does not contain the vendor libraries, firmware, raw memory, command buffers, serial numbers, credentials, or unreviewed dumps.

The original archive remains outside Git at the local evidence location used during analysis. Each metadata file names its local source in a comment or in the associated report. Hashes and interpretations must remain separate from raw output.

A future device capture should record model, build, kernel, exact GPU revision, firmware versions, SELinux state, root context, commands, raw output, and a safety/recovery note.
