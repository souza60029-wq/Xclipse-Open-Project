# Contributing

Contributions should improve evidence, documentation, tooling, or reproducibility without overstating what has been demonstrated.

Every new technical claim must include its source or experiment record. Keep raw and interpreted artifacts separate. Name tests according to the capability they actually execute. A helper that initializes a test environment must not be described as a compute, rendering, or queue-submission test.

Do not submit proprietary Samsung source, firmware, dumps containing secrets, device identifiers, or unreviewed command buffers. Open an issue when the legal status, safety impact, or recovery path is unclear.
